Welcome to Webserv

Demo page for ./webserv config/cgi_test.conf on port 8080. Each section tests one feature of the server.

1. Static files (GET)

Images loaded by this page (one extra GET request each, served as image/png):

  • /images/42_logo.png: binary file (image/png)
  • /images/: directory, its index.html is served
  • /does-not-exist: 404 (default error page)

2. Location with its own root and index

location /directory is rooted in ./YoupiBanane with index youpi.bad_extension.

  • /directory/: serves YoupiBanane/youpi.bad_extension
  • /directory/nop/: serves YoupiBanane/nop/youpi.bad_extension
  • /directory/Yeah: no index file and autoindex off, so 404

3. Upload (POST /post_body)

The body is saved in www/uploads/ as upload-<n>.txt (n starts at 1 each time the server starts). Limit for this location: client_max_body_size 100.


	


	

		
4. Delete a file (DELETE /uploads/...)

		
location /uploads allows GET DELETE. Upload something in section 3, then delete it here
		(first time 204, second time 404).
